# CloudPath — offline-first student planning PWA

CloudPath is a browser-based study and university planning project built as an offline-capable PWA. It combines practical university information, study planning, searchable reference content and small utilities in one static web application.

## My role

The project was built mainly with AI coding tools. I defined the structure, pages and expected behaviour, provided detailed step-by-step requirements, tested generated versions in the browser, reported bugs and guided fixes and refinements.

I do **not** present the code as fully handwritten by me. This project is included as an example of AI-assisted product prototyping, manual testing and iterative UI development.

## What is included

- multi-page student information and planning interface;
- searchable content and glossary helpers;
- study, finance, housing, languages and university sections;
- 30-day planning logic;
- installable PWA manifest;
- service worker and offline support;
- responsive HTML/CSS/JavaScript interface.

## Technologies used in the project

`HTML` · `CSS` · `JavaScript` · `PWA` · `Service Worker` · `Web App Manifest` · `Netlify` · browser DevTools · AI coding tools
